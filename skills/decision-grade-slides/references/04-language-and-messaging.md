## Action title formulas

Use one of these formulas:

1. Driver -> magnitude -> implication
- "Premium churn rose 4.2pp, putting $18M ARR at risk"

2. Comparison -> gap -> action
- "SMB CAC is 38% above enterprise; rebalance paid spend"

3. Option -> benefit -> tradeoff
- "Option B delivers fastest payback with moderate integration risk"

Title rules:
- Under 15 words.
- Must include a verb.
- Must imply decision relevance.

## Language quality rules

Write for fast executive parsing:
- Prefer active voice.
- Prefer concrete nouns over abstractions.
- Prefer specific numbers over adjectives.
- Keep one idea per sentence.

Replace vague wording:
- "significant increase" -> "increased 17%"
- "some customers" -> "customers in segment C"
- "improve efficiency" -> "reduce cycle time by 2.1 days"

## Precision upgrades

When editing copy, enforce:
- Named actor (who does what).
- Named metric (what changed).
- Named baseline/comparator (relative to what).
- Named timeframe (when).

If one is missing, sentence is incomplete for strategic communication.

## Callout writing rules

Callouts should interpret evidence, not duplicate labels.

Strong callout pattern:
- Observation + consequence + optional action cue.

Example:
- "Two enterprise accounts drive 61% of churn risk; prioritize save plans this quarter."

## Consistency checklist

Across all slides, ensure consistency in:
- Term definitions.
- Time labels (Q1 FY25 vs 1Q25).
- Unit style ($M, %, bps).
- Tense (past for diagnosis, future for forecasts).
- Confidence labels (Final/Preliminary/Indicative/Illustrative).
