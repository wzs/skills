## Visual hierarchy model

Design each slide around one dominant focal object.

Hierarchy levels:
- Level 1: action title (claim).
- Level 2: primary exhibit (proof).
- Level 3: annotations/callouts (interpretation).
- Level 4: source/caveat (supporting context).

If two objects compete for level-1 attention, split the slide.

## Layout and spacing rules

Use a stable grid across deck.

Rules:
- Keep title area fixed on all content slides.
- Align chart starts/axes across adjacent slides for faster comparison.
- Use whitespace to separate semantic groups.
- Keep visual rhythm consistent (margins, gutters, annotation blocks).

Recommended composition:
- 70/30: proof visual plus implication block.
- 60/40: when interpretation requires more context.

## Typography system

Default sizing:
- Title: 24-30 pt.
- Lead line/body: 14-18 pt.
- Axis/labels/footnotes: 11-14 pt.

Rules:
- One font family, up to three weights.
- Use weight/size before color for emphasis.
- Keep sentence case for readability.
- Avoid dense all-caps labels.

## Color semantics

Assign persistent semantic meaning to colors:
- Primary series: dark neutral/blue.
- Secondary context: neutral gray.
- Focus series: single accent color.
- Risk/negative variance: red.

Never introduce extra accent colors without additional semantic category.

## Emphasis and annotation

Use annotations for interpretation, not repetition.

Good annotation content:
- Driver explanation.
- Magnitude significance.
- Decision implication.

Avoid:
- Restating axis names.
- Paragraph-length text blocks.
- Decorative icons unrelated to claim.

## Chart form defaults

Prefer encodings with better perceptual accuracy:
- Position and length first (dot plots, bars, lines).
- Area/angle only when necessary and labeled carefully.

Practical defaults:
- Use bars for ranked category comparison.
- Use lines for time progression.
- Use waterfall for bridge/decomposition narratives.
- Avoid pie/donut when precise comparison matters.
