## Decision-first framing

Define these fields before slide production:
- Decision to unlock.
- Actor who decides.
- Decision criteria (how approval is judged).
- Scope boundary (what is in main flow vs backup).

If any field is missing, pause deck build and resolve.

## Deck chapter model

Use this default chapter sequence for strategic decks:
1. Executive answer: recommendation and expected impact.
2. Context: current state and constraints.
3. Diagnosis: what is driving the problem/opportunity.
4. Options: real alternatives and tradeoffs.
5. Recommendation: chosen option and why now.
6. Economics: expected impact, cost, and risk range.
7. Plan: milestones, owners, dependencies.

Merge or split chapters based on scope, but keep this logic order.

## Argument tree rules

Build a top-down tree:
- Level 1: one answer sentence.
- Level 2: 2-5 arguments proving the answer.
- Level 3: evidence blocks proving each argument.

MECE checks for level-2 siblings:
- No overlap in definitions or ownership.
- No missing bucket required for decision.

Ordering options (choose one per sibling set):
- By impact.
- By chronology.
- By process stage.
- By segment.

## Slide archetypes

Each slide should match one archetype and data shape.

1. Diagnostic slide
- Purpose: explain what is happening.
- Required data: baseline, current state, delta, timeframe.

2. Driver slide
- Purpose: explain why it is happening.
- Required data: decomposition by factors, contribution shares.

3. Option slide
- Purpose: compare alternatives.
- Required data: consistent criteria across options, tradeoff matrix.

4. Recommendation slide
- Purpose: select path.
- Required data: rationale, expected impact range, key risks.

5. Plan slide
- Purpose: show execution logic.
- Required data: milestones, owners, timing, critical dependencies.

## Horizontal and vertical coherence tests

Horizontal test (across titles):
- Read only titles top to bottom.
- Confirm no logical jump between slides.
- Confirm final title directly answers opening decision.

Vertical test (within each slide):
- Title states a claim.
- Visual and numbers prove that claim.
- Callout states implication or action.

If any test fails, revise claim or evidence before visual polish.
