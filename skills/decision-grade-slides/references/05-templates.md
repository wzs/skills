## Deck kickoff template

Use this request template:

"Build a decision-ready deck. Return: (1) decision statement, (2) MECE argument tree, (3) 12-slide action-title stream, (4) per-slide evidence spec (claim, required data, exhibit type, implication), (5) visual system spec, (6) unresolved evidence risks."

## Rewrite template for weak decks

"Rewrite this deck for clarity and decision utility. Replace topic titles with claims, enforce one-message-per-slide, convert ambiguous wording to quantified statements, and specify missing evidence needed to validate each slide's claim."

## Data sufficiency audit template

"Audit each slide for evidence sufficiency. For every claim, classify as proven / partially proven / unsupported, explain the gap, and define minimum additional data needed."

## Visual cleanup template

"Apply high signal-to-noise redesign: strengthen hierarchy, simplify layouts, use semantic color roles, and ensure the primary claim is legible within a 3-second scan."
